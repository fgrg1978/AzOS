AzOS build system.  Usage: make <target> [VAR=value]

Configure
  config                 Edit the configuration (menuconfig). Covers the
                         userspace programs, board images and console program.
  nconfig                Same as config (menuconfig is the ncurses front end).
  oldconfig              Update .config after a Kconfig change, asking about new symbols.
  olddefconfig           Update .config after a Kconfig change, taking defaults.
  defconfig              Two questions, the ISA (default: the host's) and the domain (a preset): writes the .config of
                         a development QEMU image, then `make build && make qemu` boots it. No questions:
                         make defconfig ARCH=aarch64 PRESET=robot (domains: the names under config/fragments/presets/).
                         Combinations without a green boot row are marked experimental.
  defconfig-generic-sbc-riscv64-dev  Load a defconfig: config/defconfigs/<name>.config, or <name> assembled
                         from config/fragments/ (<preset>-<hwclass>-<arch>[-<build>][+<overlay>...]).
                         This one is the fallback when there is no .config; others:
                         defconfig-robot-sbc-riscv64+vf2, defconfig-industrial-embedded-aarch64+board-generic.
  defconfigs             Regenerate the committed config/defconfigs/ from config/fragments/.
  savedefconfig          Write the minimal form of .config to $AZOS_OUT/build/last_saved.config.

Build
  build                  Build what .config selects (default target): the kernel of its ISA
                         (CONFIG_ARCH_*), the ring-3 images and the system volume; it prints where they are.
  build-rvv              riscv64: the kernel with the vector extension (needs QEMU with -cpu rv64,v=true).
  build-pci              riscv64: the kernel with the PCI bus driver.
  build-fleet            Build the Fleet-profile kernel and its board volume.
  ucode                  The signed x86 microcode image, $AZOS_OUT/build/UCODE.BIN, from the Intel and AMD files under $AZOS_DL (mk/firmware.mk).
  busybox                Build BusyBox for riscv64, aarch64 and x86_64 (needs zig, tools/build/third_party_fetch.sh busybox).
  relibc                 Build relibc and the C programs against it, for each ISA whose configuration sets CONFIG_RELIBC (needs zig, cbindgen, tools/build/third_party_fetch.sh relibc).
  check                  Type-check the kernel without linking: make check ARCH=riscv64|aarch64|x86_64.
  micro-config           Expand config/defconfigs/generic-embedded-riscv64-dev+board-generic+micro.config into $AZOS_OUT/build/micro.config (AzOS-micro, the MCU kernel).
  micro-topology         Write and sign the micro kernel's topology ($AZOS_OUT/build/micro/topology).
  micro-check            Type-check the micro kernel (riscv32, built from source).
  micro                  Build the micro kernel: $AZOS_OUT/build/micro/azos-micro.elf (riscv32imac, M-mode, PMP).
  micro-test             Run the micro kernel's host suite.
  micro-qemu             Boot the micro kernel on QEMU virt rv32 (PMP on).

Run in QEMU
  qemu                   Boot what `make build` built: the kernel of the configured ISA (QEMU virt on
                         riscv64 and aarch64, microvm on x86_64, TCG) with a copy of its system volume,
                         so it reaches the console program.
  qemu-gdb               `make qemu` stopped at reset, waiting for a GDB connection on :1234.
  qemu-smp               riscv64: boot with 4 CPUs.
  qemu-full-smp          riscv64: boot with 4 CPUs, a disk, a network card and hello.elf.
  qemu-rvv               riscv64: boot with vector extension, one CPU.
  qemu-full-smp-rvv      riscv64: boot with vector extension, 4 CPUs, disk and network.
  qemu-pci               riscv64: boot with PCI block and NVMe devices.
  qemu-aarch64-el2       aarch64: `make qemu` with the kernel entered at EL2, as boot firmware does.
  netboot-row            Boot with nothing on a disk, the firmware fetching AzOS over the network: make netboot-row NETBOOT_CASE=x86-pxe|x86-http|riscv64-tftp (cases and canaries: tools/gate/netboot/row.sh).
  netboot-uboot          Build the riscv64 U-Boot the netboot rows boot, from the approved tarball, under $AZOS_OUT/netboot.
  azos-guest             AzOS inside AzOS: the hypervisor kernel, a guest kernel and the host volume that carries it: make azos-guest ARCH=riscv64|aarch64; boot with tools/dev/run_guest.sh <isa>.

Boards
  vf2                    Build for the VisionFive 2 (JH7110).
  flash-vf2              Write the VisionFive 2 kernel to an SD card (VF2_SD=<dev>).
  vf2-ktest              Farm: build the DEV test kernel, boot it on the board, judge the ktest TAP (tools/dev/farm/README.md).
  vf2-pstore             Farm: the pstore boot counter on the board (two boots, one panic, the record recovered).
  vf2-console            Open the VisionFive 2 serial console (VF2_SERIAL=<dev>).
  k1                     Build for the SpacemiT K1 / BananaPi BPI-F3.
  flash-k1               Write the K1 kernel to an SD card (K1_SD=<dev>).
  k1-console             Open the K1 serial console (K1_SERIAL=<dev>).
  rpi5                   Raspberry Pi 5: needs TOPOLOGY_PUBKEY_PATH; the build stops at a compile_error naming the console, boot and EL2 pieces the board needs.

Test & gate
  check0                 Quick check after an edit: type-check riscv64, aarch64 and x86_64, run the host tests the diff reaches.
  lint                   Every lint of the tree (tools/ layout, Kconfig, docs, unsafe budget, ...); builds nothing.
  check-presets          Every preset expands on riscv64, aarch64 and x86_64 and the cargo bridge accepts it (no build).
  sdk                    The native SDK of the .config ISA, into $AZOS_OUT/sdk/<isa>: std for <isa>-unknown-azos, rebuilt only when the toolchain, the port layer or a Kconfig value it is built with changes. `make build` runs it first.
  sdk-check              The std port layer type-checks on the three ISAs; its host tests and the proc-macros' run.
  check-neverallow       No preset's, defconfig's or micro's topology breaks a neverallow rule (host builds, no boot).
  unsafe-budget          Unsafe counts, #![forbid(unsafe_code)] and the kernel's unsafe share against tools/lint/unsafe_budget.tsv.
  size-check             Build the riscv64 QEMU defconfig kernel; its section sizes against tools/lint/size_budget.tsv.
  size-update REASON=..  Rebuild it and move tools/lint/size_budget.tsv, recording why.
  check1                 Change check: check0, then smoke boots and the QEMU scenarios the diff maps to.
  check-fast             Fronts' check: per ISA one ktest boot, one runtime-canary boot, one abitest boot.
  ci                     The full gate (long; run before pushing).
  ci-full                The full gate plus the AzOSRobotBrain tests and protocol sync.
  qemu-systest           Run the system-call test program in ring 3.
  qemu-dhcp-smoke        Check that DHCP reaches Bound against QEMU's server.
  qemu-net-pair          Boot two kernels and exchange a TCP payload.
  lx-compare             Compare instruction counts against Linux on the same QEMU.

Release & OTA
  $AZOS_OUT/build/disk-signed.img  FAT32 image with KERN_A.BIN and a valid KERN_A.SIG.
  $AZOS_OUT/build/disk-badsig.img  Same, with one bit of the signature flipped.
  $AZOS_OUT/build/disk-sh-signed.img  The shell volume (installer, pkg, ota) with a signed slot A.
  topology-files         Write the signed capability topology files for both ISAs.
  sim                    Dry-boot a topology on the host (SIM_DEFCONFIG=, SIM_TOPOLOGY=, SIM_CPUS=).
  ota-send               Send firmware to a robot over TCP (ROBOT=, PORT=, PLATFORM=, FW_VER=).
  tftp-serve             Serve the firmware image over TFTP (TFTP_PORT=, default 6969).
  boot-scr               Generate the U-Boot A/B slot-selection script.

Maintenance
  clean                  Remove build artifacts.
  prune                  Delete stale build variants (PRUNE_ARGS=--dry-run to only report).
  worktree-seed          Seed a fresh worktree's cargo caches from another (FROM=<worktree>; SEED_ARGS=--dry-run).
  make-gguf              Generate $AZOS_OUT/build/policy.gguf.

Variables
  QEMU_LOG_LEVEL=err|warn|info|debug   Log level of the QEMU kernels (default debug).
  QEMU_X86_64_UCODE=<UCODE.BIN>        x86_64 `make qemu`: the microcode image as the boot module.
  AARCH64_PAGE_SIZE=4096|16384|65536   Page size of the aarch64 kernel and programs.
  ARCH=riscv64|aarch64|x86_64          Target of `make check`, `make doc` and `make azos-guest`; default: the ISA of .config.
  TOPOLOGY_PUBKEY_PATH=<file>          Fleet public key; vf2, k1 and build-fleet refuse to build without it.
  NETBOOT_CASE=<case>                  netboot-row: the row to run (default x86-pxe; the list is at the top of tools/gate/netboot/row.sh).
  BUILD_TYPE=DEV                       vf2 only: a development image (the TEST key allowed, KTEST possible); unset is the product build.

Boot the signed-image fixtures with the secure-boot-enforced selection and an
absolute PROD_PUBKEY_PATH, for example $PWD/tools/keys/test_pub.bin.
