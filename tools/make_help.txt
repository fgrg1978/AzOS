AzOS build system.  Usage: make <target> [VAR=value]

Configure
  config                 Edit the configuration (menuconfig). Covers the
                         userspace programs, board images and console program.
  nconfig                Same, with the ncurses front end.
  oldconfig              Update .config after a Kconfig change, asking about new symbols.
  olddefconfig           Update .config after a Kconfig change, taking defaults.
  defconfig-edge         Load the Edge profile (default for RISC-V on QEMU).
  defconfig-embedded     Load the Embedded profile (smallest footprint).
  defconfig-fleet        Load the Fleet profile (gateway boards, 1 GiB+ RAM).
  defconfig-vf2          Load the VisionFive 2 configuration.
  defconfig-k1           Load the SpacemiT K1 configuration.
  defconfig-rpi5         Load the Raspberry Pi 5 configuration (not ported yet).
  savedefconfig          Write the minimal form of .config to config/defconfigs/last_saved.config.

Build
  build                  Build the RISC-V kernel for QEMU (default target).
  build-rvv              Same, with the RISC-V vector extension (needs QEMU with -cpu rv64,v=true).
  build-pci              Same, with the PCI bus driver.
  build-fleet            Build the Fleet-profile kernel and its board volume.
  aarch64                Build the aarch64 kernel for QEMU virt (build/kernel-aarch64.img).
  x86_64                 Build the x86_64 port skeleton; it stops at the first piece not ported.
  userspace              Build the RISC-V user-space programs.
  userspace-aarch64      Build the aarch64 user-space programs.
  busybox                Build BusyBox for both ISAs (needs zig).
  check                  Type-check the kernel without linking: make check ARCH=riscv64|aarch64|x86_64.

Run in QEMU
  qemu                   Boot the kernel on one CPU.
  qemu-smp               Boot with 4 CPUs.
  qemu-full-smp          Boot with 4 CPUs, a disk, a network card and hello.elf.
  qemu-rvv               Boot with vector extension, one CPU.
  qemu-full-smp-rvv      Boot with vector extension, 4 CPUs, disk and network.
  qemu-gdb               Boot and wait for a GDB connection on :1234.
  qemu-pci               Boot with PCI block and NVMe devices.
  qemu-aarch64           Boot the aarch64 kernel (QEMU virt, entered at EL1).
  qemu-aarch64-el2       Boot the aarch64 kernel entered at EL2, as boot firmware does.
  qemu-x86_64            Boot the x86_64 skeleton on QEMU microvm.

Boards
  vf2                    Build for the VisionFive 2 (JH7110).
  flash-vf2              Write the VisionFive 2 kernel to an SD card (VF2_SD=<dev>).
  vf2-console            Open the VisionFive 2 serial console (VF2_SERIAL=<dev>).
  k1                     Build for the SpacemiT K1 / BananaPi BPI-F3.
  flash-k1               Write the K1 kernel to an SD card (K1_SD=<dev>).
  k1-console             Open the K1 serial console (K1_SERIAL=<dev>).
  rpi5                   Raspberry Pi 5: not ported; needs TOPOLOGY_PUBKEY_PATH, then stops and says what is missing.

Test & gate
  check0                 Quick check after an edit: type-check riscv64, aarch64 and x86_64, run the host tests the diff reaches.
  check1                 Change check: check0, then smoke boots and the QEMU scenarios the diff maps to.
  ci                     The full gate (long; run before pushing).
  ci-full                The full gate plus the AzOSRobotBrain tests and protocol sync.
  qemu-systest           Run the system-call test program in ring 3.
  qemu-dhcp-smoke        Check that DHCP reaches Bound against QEMU's server.
  qemu-pi-smoke          Check priority donation on a single CPU.
  qemu-net-pair          Boot two kernels and exchange a TCP payload.
  qemu-tftp-smoke        Fetch a file over TFTP from QEMU's server.
  qemu-aarch64-smoke     Run the aarch64 bring-up smoke test.
  lx-compare             Compare instruction counts against Linux on the same QEMU.

Release & OTA
  build/disk-signed.img  FAT32 image with KERN_A.BIN and a valid KERN_A.SIG.
  build/disk-badsig.img  Same, with one bit of the signature flipped.
  topology-files         Write the signed capability topology files for both ISAs.
  ota-send               Send firmware to a robot over TCP (ROBOT=, PORT=, PLATFORM=, FW_VER=).
  tftp-serve             Serve the firmware image over TFTP (TFTP_PORT=, default 6969).
  boot-scr               Generate the U-Boot A/B slot-selection script.

Maintenance
  clean                  Remove build artifacts.
  prune                  Delete stale build variants (PRUNE_ARGS=--dry-run to only report).
  worktree-seed          Seed a fresh worktree's cargo caches from another (FROM=<worktree>; SEED_ARGS=--dry-run).
  make-mlp               Generate build/mlp.rmlp (the ML weight file).
  make-gguf              Generate build/policy.gguf.

Variables
  QEMU_LOG_LEVEL=err|warn|info|debug   Log level of the QEMU kernels (default debug).
  AARCH64_PAGE_SIZE=4096|16384|65536   Page size of the aarch64 kernel and programs.
  ARCH=riscv64|aarch64|x86_64          Target of `make check`.
  TOPOLOGY_PUBKEY_PATH=<file>          Fleet public key; vf2, k1 and build-fleet refuse to build without it.

Boot the signed-image fixtures with --features qemu,secure-boot-enforced and an
absolute PROD_PUBKEY_PATH, for example $PWD/tools/keys/test_pub.bin.
